# Contribution Guidelines

Thanks for helping Iranian developers ship faster. Please make sure your pull request follows these rules.

## What belongs here
- Tools, libraries, services and datasets that solve a problem **specific to building software for Iran or Persian-speaking users**.
- Open-source projects must be **actively maintained** (not archived, with activity in the last two years) and have a README in English or Persian that explains usage.
- Commercial services are welcome if they offer a developer API or a free tier, and the link goes to the product, not an affiliate URL.
- Not accepted: your own project with no users yet, abandoned forks, tutorials behind paywalls, or anything unrelated to development.

## Format
- One item per pull request, unless they are closely related.
- Add the item to the most specific section, at the end of the list (or in order of relevance if you know it is the best option).
- Use this format, with the description starting with a capital letter and ending with a period:

  ```markdown
  - [Project Name](https://github.com/owner/repo) - Short description of what it does.
  ```
- Keep descriptions short and factual. No marketing words like "best", "amazing" or "powerful".
- Use the project's official name and link to its repository or official website.

## Before submitting
- Search the list to avoid duplicates.
- Check that the link works and the project is not archived.
- Use a clear PR title: `Add <project name>`.

## Removing items
If you find a dead link or an abandoned project, open a PR to remove it and explain why.
